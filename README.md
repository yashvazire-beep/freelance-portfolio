# Freelance Portfolio (React + Vite)

## Requirements
- Node.js LTS: https://nodejs.org/
- VS Code (optional): https://code.visualstudio.com/

## Run locally
1. Extract this ZIP.
2. Open the extracted `freelance-portfolio` folder in VS Code.
3. Choose Terminal > New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL Vite prints (usually http://localhost:5173).

## Before publishing
- In `src/App.jsx`, replace `YOUR_EMAIL@example.com` with your real email.
- The Daily Brew Café is a fictional portfolio concept. Keep it labelled as sample work.
- The café card currently uses a CSS preview; add your actual Canva exports to show original images.

## Build for deployment
Run `npm run build`. Production files are generated in `dist/`.

## Free deployment
1. Upload the extracted project files to a GitHub repository.
2. Import the repository into Vercel.
3. Build command: `npm run build`; output directory: `dist`.
4. Deploy and test the public URL.
